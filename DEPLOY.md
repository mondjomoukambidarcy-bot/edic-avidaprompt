# 🚀 Déployer EDIc avidaPROMPT IA

## Option 1 — Vercel (recommandé, 1 clic, gratuit)

1. Créez un compte sur https://vercel.com (gratuit)
2. Installez Vercel CLI : `npm i -g vercel`
3. Dans le dossier du projet : `vercel`
4. Suivez les instructions (Entrée, Entrée, Entrée)
5. Votre site est en ligne à `https://edic-avidaprompt-ia.vercel.app`

## Option 2 — Netlify Drop (encore plus simple)

1. Allez sur https://app.netlify.com/drop
2. Glissez-déposez le dossier `edic-avidaprompt/`
3. C'est en ligne. Immédiatement.

## Option 3 — GitHub Pages (pour l'archive)

1. Créez un repo `edic-avidaprompt-ia`
2. Poussez le code
3. Settings → Pages → Deploy from main branch
4. URL : `https://[votre-pseudo].github.io/edic-avidaprompt-ia`

## Domaine personnalisé (optionnel)

Sur Vercel/Netlify : Settings → Domains → ajoutez `edic-darcy.dev` (~10 €/an)
