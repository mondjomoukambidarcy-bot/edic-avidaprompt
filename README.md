---

## 🎯 Qu'est-ce que c'est ?

**EDIc avidaPROMPT IA** est un outil qui aide à écrire des **prompts qui tiennent** :
structurés, testés, partagés. Il transforme le "vide-coding" (construire
du logiciel en parlant à une IA) en une pratique **précise, honnête et reproductible**.

## ✨ Ce que vous y trouverez

| Zone | Rôle |
|------|------|
| 🧪 **Laboratoire** | Éditeur visuel de scripts — construisez vos prompts en blocs |
| 🔐 **Sécurité** | Tests de robustesse éthique (red-team documenté) |
| ⚙️ **Développement** | Scripts "idée → code" fonctionnel |
| 🧠 **Pensée** | Scripts de raisonnement, décision, philosophie |
| 📖 **Documentation** | Manifeste, protocoles, méthode |

## 🚀 Utilisation

1. Ouvrez `index.html` dans un navigateur (double-clic)
2. Cliquez **"Ouvrir l'application"**
3. Choisissez une zone, ouvrez un script, copiez-le dans votre IA préférée

Aucune installation. Aucune dépendance. Aucun compte.

## 🛠️ Stack

- HTML + CSS + JS **vanilla** (aucun framework)
- Bilingue FR/EN
- Thème dark cyber / light éditorial
- Persistance `localStorage`
- Déployable en 1 clic (Vercel / Netlify / GitHub Pages)

## 📜 Manifeste

> Je ne suis pas développeur au sens où on l'entend.
> Je n'ai pas de diplôme, pas de titre, pas de bureau dans la Silicon Valley.
> Je suis quelqu'un qui a vu une porte — celle du vide-coding —
> et qui a voulu y laisser une trace utile avant qu'elle ne se referme.
>
> Ce projet n'attaque aucune IA. Il ne contourne aucune règle.
> Il ne cherche pas à manipuler, à tromper, à nuire.
> Il fait une seule chose : **donner à ceux qui n'ont rien
> les moyens de créer quelque chose.**
>
> — Darcy
